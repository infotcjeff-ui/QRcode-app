UI: 4 項主要修正

1. 高度修正 (site-wide + login)
   - globals.css 新增 html { height: 100%; }，讓子元素 h-full 能正確解析
     到 viewport，避免 flex column 父容器 min-h-screen 時百分比失效造成
     登入頁內容貼頂的問題。
   - layout.tsx 的 body 與內層 div 由 min-h-screen 改為 min-h-svh，
     100svh 避免手機 PWA / Safari 被網址列遮擋。
   - /login 與 /lock 的 <main> 由 h-full 改為 h-svh，加入 overflow-y-auto
     處理極短螢幕被裁切的風險。

2. 站點密碼單次輸入 (site-wide)
   - /lock 頁面從「輸入密碼 → 再次確認」雙步驟簡化為單步驟。
   - 驗證成功設定 12 小時 bus_site_access cookie 後直接導向 ?next=
     指定路徑(或預設 /login)；不再清空已存在的 cookie。
   - / 主頁不再呼叫 clearSiteAccessCookie()，避免 cookie 被誤刪而需
     重複輸入站點密碼。

3. 登入後 default 到主頁 (/)
   - /login 完成登入後的目標路徑：若 query 提供 next=… 且為站內相對
     路徑才採用；否則一律 / (主頁)。
   - 不再依角色分流到 /system-setting 或 /scan。

4. 主頁內容調整
   - 移除「底部導覽列可快速切換… 」提示卡片。
   - 整體版面改為 h-svh + flex items-center justify-center，視覺上
     內容垂直水平置中。
   - 移除 clearSiteAccessCookie() 的副作用呼叫。
